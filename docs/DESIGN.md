# 1.1.0 设计与边界

实现状态（2026-11-11）：本设计已落地并通过扩展回归、真实 Edge + 未修改宿主客户端验证；目标机器尚未安装。发行包 1.1.0 与 1.0.0 并存。

## 架构

保持两个官方用户模块：

1. `voice`：同名替换的合成入口，基于内置复制。负责本地接口优先、Breeze/原引擎、RVC、ASR和兼容路由。
2. `breeze-settings`（显示名「增强语音」）：独立控制台与模式管理。无 `tab` 字段，宿主自动给予独立页。沿用已有ID与 `ext['breeze-settings']`，保护1.0.0配置。

不替换/补丁/注入宿主前端；界面只用官方 `panel`、`api.route`、`api.config/setConfig`、`api.settings/saveSettings`、`api.use/has` 与 `api.core` 已开放能力。

## 模式

| 用户选择 | modules.voice.enabled | modules.voice.useBuiltin | voice.enabled | 实际运行 |
|---|---|---|---|---|
| 增强 | true | false | true | 用户版 voice |
| 官方 | true | true | true | 官方 voice |
| 关闭 | false | 保留 | false | 无 voice |

- 控制台自身保持加载，关闭语音后仍可重新选择模式。
- 选择使用官方是切换，不是让两版同时跑；官方配置仍在原 `voice` 字段。
- 检测 safeMode、缺少voice、加载失败回退并展示；不得假报已启用增强。
- 配置保存与生效分清：模式切换为显式即时操作；引擎与参数保存后生效，试听只用已保存值。
- 更新整份配置时只合并语音相关字段，避免覆盖其他模块或旧的并发草稿。

## 界面

- 独立页名称「增强语音」，简洁标题和实际模式状态，不做统计仪表盘。
- 第一行三态互斥选择；下方引擎分组：「远程 Breeze」「原有引擎」。按选择展示配置，无重复全量自动表单。
- Breeze基本项（固定官方服务地址、Key、Voice ID/取列表、模型）显著；速度/音量/表演指令按常用/高级组织。
- 原有引擎保留官方控制页，并提供必要的引擎选择/跳转说明；不重写ASR/RVC整个管理页。
- 试听在当前配置旁，不在超长页末尾；错误、未保存提醒、真实运行模式清晰。
- 原生主题变量、键盘可达控件、响应式；不使用自定义DOM改写来藏原页面。

## 配置安全

- Key必须保持password登记，即使改为自绘表单。若需要避免宿主生成重复表单，利用服务端 `registerSecretField` 的已公开内部lib，并保留密钥更新/空值语义测试。
- 管理和试听继续限回环+Host+Origin+请求方法，不将Key返给浏览器。
- 配置路由只接受明确允许的字段；不接受客户端整份配置或 arbitrary module ID。
- 不自动请求付费API，不自动重试计费请求。
