## 关键规则

- 同名 `voice` 替换才能被宿主 `use('voice').speak()` 调用；不能仅新建不同 id 并关掉 voice。
- 独立界面继续用 `breeze-settings` ID，改显示名称为「增强语音」并取消 `tab:'voice'`，避免迁移已保存 ext 配置。
- `modules.voice.enabled=false` 表示关闭两版；`enabled=true,useBuiltin=true` 表示官方；`enabled=true,useBuiltin=false` 表示用户增强。开启模式时同步 voice.enabled，避免双重开关状态不清。
- 原宿主加载失败自动回退内置，不破坏该兜底；界面必须区分期望模式与实际运行状态。
