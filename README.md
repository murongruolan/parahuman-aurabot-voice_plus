# ParaHuman · Aurabot Voice Plus

基于 Aurabot 官方 `voice` 复制机制的用户语音增强模块：独立「增强语音」控制台、增强/官方/关闭三态、BreezeBlue 远程 TTS、情绪路由。**不修改宿主源码，不在开发电脑 DSH 安装。**

## 当前状态

- **1.0.0 基线**：Breeze API 与目标机器 QQ 发语音由用户确认可用，发行包保留作回滚。
- **1.1.x**：独立控制台、三态切换、控制台回退提示（1.1.1）、连接级失败自动重试（1.1.2，默认 2 次/1 秒；HTTP 状态错误与超时永不重试）。
- **1.2.0**：`api.rule` 提示词规则——`<voice>` 内用中文标点分句，不要只用空格。
- **1.3.0 → 1.4.0（最新）**：情绪路由。三层情绪（8 核心情绪 / L·M·H 唤醒 / 8 副语言）以内容内标记 `[excited:H]…[laugh]` 表达；「情绪引擎」tab 按情绪路由到 Breeze / 原有引擎 / 自定义 HTTP 端点，支持端点列表与情绪预设（绑定 Voice ID）。1.4.0 按 387 条矩阵实测修正：五字段请求（不再发送 speed/volume）、句首「……」吞字预处理、文本+参数 hash 缓存防重复计费、429 退避重试、402×3 熔断 10 分钟、情绪指令×唤醒度 guidance（轻2/标准4/强烈6）相交、promptTags 提示词开关。148 项扩展回归、真实 Edge + 未修改宿主客户端浏览器验证通过；**目标机器待实装 1.4.0 验收**。

## 目录

- `modules/voice`：同名替换的合成入口（Breeze、原引擎、情绪端点、RVC、ASR）。
- `modules/breeze-settings`：独立「增强语音」控制台（配置、三态、情绪端点与模板）。
- `test`：离线契约、真实 loader、面板、访问保护、安装检查（`node scripts/tasks.mjs test`）。
- `scripts`：开发、浏览器验证、打包工具。
- `upstream` / `dist` / `artifacts` / `.private`：本机只读上游快照、发行包、验证产物、私密配置，均不进 git。

详细文档（使用说明、测试报告、交接与进度）按约定移出仓库，仓库外备份于 `aurabot-voice-docs-backup-20261111`；发行包内保留《先读我.txt》安装步骤。
