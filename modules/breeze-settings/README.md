# 增强语音控制台（配合 voice 扩展）

必须与本发行包的 `voice` 文件夹一同安装到目标 Aurabot 的用户模块目录。

Aurabot 1.2.0 不显示同名内置替换模块的自定义设置，因此本模块使用独立 ID `breeze-settings`，显示名「增强语音」，不设置 `tab` 字段，由宿主生成独立导航页。它不注册聊天钩子、不改提示词、不自行合成；实际合成仍由复制的 `voice` 模块完成。

- 三态互斥：增强语音（用户版 voice）/ 官方语音（内置 voice）/ 关闭语音（不运行 voice）。控制台自身在三种状态下都保持可用。
- 独立页面沿用 1.0.0 的 `ext['breeze-settings']` 配置，Key、Voice ID、原引擎参数不会因页面重写或模式切换而丢失。
- 页面分「远程 Breeze」「原有引擎」两组；保存后才生效，试听使用已保存配置。
- Key 保存于 `config.ext["breeze-settings"].apiKey`，按密码字段脱敏，不在代码里、不回显给浏览器。
- 控制台与试听接口限目标机器回环直连，拒绝外部及反代请求；QQ 聊天语音不受这一管理接口限制。
- RVC、ASR、本地 TTS 接管、安装组件仍在原「语音」页，保持原功能。

升级自 1.0.0：先备份并移出旧的 `voice` 与 `breeze-settings` 目录，再复制本包两个目录；配置保存在 DSH 配置中，不会被模块文件替换清除。详细步骤见发行包根目录《使用说明.md》。
