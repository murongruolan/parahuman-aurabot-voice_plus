# BreezeBlue 语音设置（配套模块）

必须与本发行包的 `voice` 文件夹一同安装在目标 Aurabot 用户模块目录。

Aurabot 1.2.0 不显示同名内置替换模块的自定义设置，所以本模块使用独立 ID `breeze-settings`，将设置和面板嵌入原“语音”页。它不注册聊天钩子，不改提示词，不自行合成；实际合成仍由复制的 `voice` 模块完成。

- 保持两个模块启用；voice 使用用户版本。
- 在目标机器本地（或远程桌面内）打开 DSH 面板，填写 Key/Voice ID、选择 BreezeBlue 并保存。
- Key 保存于 `config.ext["breeze-settings"].apiKey`，按密码字段脱敏，不在代码里。
- 关闭此配套模块后，新发起聊天语音回到原引擎，不再使用已存 Breeze 配置。
- 新增查询/试听接口限目标机器回环直连，拒绝外部及反代请求。QQ 聊天语音不受这一管理接口限制。

完整步骤见发行包根目录《使用说明.md》。
